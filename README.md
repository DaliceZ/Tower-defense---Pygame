# 204454_tower_defense

## Project Setup Guide | คู่มือการติดตั้งโปรเจค

This project requires:

- Python 3.12.10
- pygame 2.6.1

---

## Automatic Installation (Recommended) | การติดตั้งแบบอัตโนมัติ (แนะนำ)

This step will install **Miniconda** and create a **virtual environment**.

### For Windows

1. Run `install-window.bat` inside the project folder.
2. Follow the instructions in the CMD.
   - It may ask to run `install-window.bat` again to install game dependencies as if you have installed Miniconda for the first time.

### For Linux (Ubuntu/Debian)

1. Open a terminal.
2. Navigate to the project directory.
3. Run `install-linux.sh` inside the project directory.

```bash
chmod +x install-linux.sh
./install-linux.sh
```

---

## How to Run | วิธีเล่น

### For Windows

1. Run `run-window.bat` inside the project folder.

### For Linux

1. Open a terminal.
2. Navigate to the project directory.
3. Run `run-linux.sh` inside the project directory.

```bash
chmod +x run-linux.sh
./run-linux.sh
```
